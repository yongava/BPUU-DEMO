### 6.1 แจ้งรับเรื่อง (Ticket Received) — ตั้งที่ **ฟอร์มหลัก → Settings → Emails → Autoresponder** (ยังไม่ได้ตั้ง)
- ถึง: อีเมลผู้ยื่นคำขอ · เรื่อง: `[Received] ระบบได้รับคำขอใช้บริการ {ประเภทคำขอ} ของท่านแล้ว (Ref: {id})`
- เนื้อหา: เรียน คุณ{ชื่อ-สกุลผู้ยื่นคำขอ} / ระบบกระบวนงาน BPUU ได้รับคำขอ "{ประเภทคำขอ}" ของท่านเรียบร้อยแล้ว / หมายเลขคำขอ: {id} / สถานะ: รอการตรวจสอบ / เจ้าหน้าที่จะแจ้งผลผ่านอีเมลนี้ / ขอแสดงความนับถือ กลุ่มงานจัดการผลประโยชน์และทรัพย์สิน (BPUU) มจธ.

### 6.2 ขออนุมัติ (Approval Request) — ใช้กับ**ทุกกล่องอนุมัติใหม่** (EDIT EMAIL)
- เรื่อง: `[Action Required] อนุมัติคำขอใช้บริการ {ประเภทคำขอ} — คุณ{ชื่อ-สกุลผู้ยื่นคำขอ}`
- เนื้อหา: เรียน ผู้มีอำนาจอนุมัติ / มีคำขอใหม่รอการพิจารณา: ผู้ขอ {ชื่อ-สกุล} · ประเภท {ประเภทคำขอ} · รายละเอียดตามด้านบน / กรุณากดปุ่มเพื่อพิจารณา
- **สำคัญ:** กดไอคอนรูปตา 👁 → ติ๊ก **Approve + Deny** ทุกครั้ง ไม่งั้นเมลไม่มีปุ่ม
