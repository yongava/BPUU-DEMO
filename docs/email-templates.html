ต้นแบบเทมเพลตอีเมล (Email Template Prototypes)

ชุดต้นแบบสำหรับ JotForm Workflow — ใช้เป็นมาตรฐานหน้าตาของอีเมลทุกประเภทในระบบ ตัวอย่างด้านล่างแสดงผลแบบเดียวกับที่ผู้รับเห็นในกล่องจดหมาย และมีโค้ด HTML พร้อมคัดลอกไปวางในตัวแก้เมลของ JotForm

วิธีใช้ & ข้อตกลง

  • ตัวแปรในวงเล็บปีกกา เช่น {ชื่อ-สกุลผู้ยื่นคำขอ} {ประเภทคำขอ} {id} คือ ฟิลด์จากฟอร์ม — ในตัวแก้เมล JotForm ให้แทรกจากเมนู Fields (โทเคนจริงอาจต่างจากข้อความนี้ ให้ลบข้อความตัวอย่างแล้วแทรกฟิลด์ทับ)
  • {SITE_URL} = URL เว็บจริงของระบบแบบเต็ม ต้องขึ้นต้นด้วย https:// (เช่น https://bpuu.netlify.app) — ถ้าใส่เป็นโดเมนเปล่าไม่มี https:// JotForm จะเติม URL ของ workflow นำหน้า ทำให้ลิงก์กลายเป็น 404
  • ปุ่ม Approve / Deny และปุ่ม กรอกฟอร์ม (View Form) เป็นปุ่มที่ ระบบ JotForm แทรกให้อัตโนมัติ — ในต้นแบบจะแสดงเป็นกรอบประ "ตัวอย่าง" เพื่อให้เห็นตำแหน่ง อย่าก๊อปปุ่มตัวอย่างไปใช้จริง
  • โค้ด HTML ใช้โครงสร้างตาราง + inline CSS ให้แสดงผลได้ทุกโปรแกรมอีเมล (Gmail / Outlook / มือถือ) — คัดลอกทั้งก้อนไปวางในโหมด Source (</>) ของตัวแก้เมล
