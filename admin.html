เปิด JotForm Tables เปิด Inbox อนุมัติ
โหมดเดโม่: หน้านี้ฝัง API key ไว้ในตัวเว็บ ใครเข้าถึงหน้านี้ได้ = อ่าน/แก้ข้อมูลทุกคำขอได้ — ก่อนใช้งานจริงต้องย้าย key ไปฝั่งเซิร์ฟเวอร์ (proxy) และ revoke key ชุดนี้
หน้านี้ดึงข้อมูล เอกสารแนบ และเชื่อมสลิปให้อัตโนมัติ — ไม่ต้องเปิด JotForm Inbox เพื่อดูข้อมูลอีกต่อไป ยกเว้นขั้นตอน กดอนุมัติ/ปฏิเสธ ซึ่ง JotForm ผูกกับลิงก์เฉพาะในอีเมลของผู้อนุมัติแต่ละคน ไม่มี API ให้กดแทนได้ — ขั้นนั้นยังต้องเปิดอีเมล/Inbox ตามปกติ
สลิปที่ส่งเข้ามาจากฟอร์มชำระเงิน — กดเปิดดูรูปแล้วไปกดยืนยันใน Inbox ของฟอร์มสลิป
